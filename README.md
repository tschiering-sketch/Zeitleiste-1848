# Zeitleiste Revolution 1848/49

Interaktive Zeitleiste für Geschichte, Jahrgangsstufe 12 (LehrplanPLUS Bayern, Lernbereich 12.1.1), im Hausstil des Gymnasiums Leopoldinum Passau.

- `index.html`: fertige, eigenständige Seite (Schrift und Logo eingebettet), im Browser öffnen
- `src/zeitleiste.html`: Quelltext mit Inhalten (Ereignisse, Nachfragen, Erwartungshorizonte)
- `build.py`: erzeugt `index.html` aus Quelltext und `assets/`

Nach Änderungen am Quelltext: `python3 build.py`
